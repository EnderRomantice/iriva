# Slack-Lato

https://a.slack-edge.com/bv1-13/legacy-style-libs-lato-2-compressed.f97f6fd36fc9636d.min.css

Referenced by the public https://app.slack.com/client document. Original official CDN files:
- https://a.slack-edge.com/bv1-13/lato-regular-ef8e44a2b506169e.woff2 (400)
- https://a.slack-edge.com/bv1-13/lato-bold-78da5d4476a83d65.woff2 (700)

Files are unchanged, served locally through next/font/local. Lato's SIL Open Font License is included in OFL.txt. Chinese glyphs fall back to PingFang SC / Microsoft YaHei / system sans-serif; Lato is not a Chinese typeface. No Slack logo or icon font is used.
