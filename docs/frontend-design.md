# IRIVA 工作区视觉规范

以用户提供的 Slack 工作区截图为结构参考：蓝色外框与顶部搜索、极窄全局导航、浅色工作区侧栏、白色频道主区。内容与业务属于 IRIVA，不保留旧 Dashboard 卡片布局。

## 结构与字体

- 新界面位于 `features/space`，样式集中在 `app/(workspace)/space.css`。
- 学员、Host、运营共享工作区外壳，各自显示练习、反馈、日程、伙伴或报名组班。
- 首页仅显示欢迎语、下一次圆桌和当前练习；列表与右侧详情抽屉承载其余信息。
- 按 Slack 参考截图重建 40px 顶栏、68px 主导航和 336px 工作区侧栏。恢复带文字的线性图标、组织头像、频道标题、下划线标签与姓名头像。顶栏左侧不显示额外品牌文字。
- 使用 Slack 官方 CDN 的 Slack-Lato 400、700、900 原始字体文件，通过 `next/font/local` 本地加载。来源及 OFL 授权见 `app/fonts/README.md`；中文回退至 PingFang SC / Microsoft YaHei。

## 配置与交互

- 默认海湾蓝 `#12658a`。可选择茄紫、松林、石墨或任意自定义色，自动衍生侧栏、选中态与主操作颜色。
- 外观支持深色内容区、紧凑间距、收起侧栏；导航可显隐和排序。配置按机构存入当前浏览器，下次打开自动恢复。
- 顶部搜索过滤实际练习或报名记录；Cmd/Ctrl+K 聚焦搜索。前进、后退与历史菜单恢复机构、小组及内容视图；继续浏览会清除旧的前进分支。
- 悬停约 150ms，内容进入约 200ms，抽屉约 250ms；尊重 reduced-motion。原生 dialog 支持焦点约束、Escape 和背景关闭。
- 760px 以下侧栏转为抽屉，保留导航、机构切换与个人资料入口；宽度、间距与表单随屏幕调整。

## 本地优先

编辑器先将草稿自动保存到 IndexedDB。提交和完成状态沿用已有乐观更新队列，网络恢复后同步；冲突在同步详情中处理。切换 Household 同时过滤课程、练习、提交和反馈。后端、数据库迁移边界与命令合同保持独立于界面。

本地开发可在自定义面板切换模拟离线和慢网，用于验证草稿恢复与同步。

机构头像与工作区标题都可打开切换菜单；星标和菜单操作均连接真实界面状态。Common Ground 是用于验证隔离的第二个演示机构，不是 IRIVA 内的 Household。菜单使用 transitions-dev 的下拉动效，并支持 Escape、上下方向键、点击外部关闭和减少动态效果。
