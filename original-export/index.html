常见问题

我的英语要到什么水平？

能用英语聊 5 分钟“你今天做了什么”就可以，慢一点没关系。你不需要先变得流利，才能加入对话。零基础暂时不适合这个形式。

时间怎么定？

报名时勾选你每周的可用时段。我们把时间对得上、目标相近的 4 位伙伴组成一个 Household，再和 Host 确认圆桌时间，整个学期固定。一对一和伙伴练习自己约。

Host 是什么样的人？

基础档是英语流利的国际 Host，母语档是英语母语者，职业档是有商业工作背景的母语者。每位 Host 都先和真实学习者试聊，温暖、会倾听，才会带 Household。

缺席了怎么办？

圆桌时间固定，缺席不单独补课，由一对一和伙伴练习补上。你的伙伴在等你，这也是大家能坚持下来的原因。

录音和数据怎么用？

录音转写须事先书面同意，只用来生成你的反馈和报告，不对外分享，学期结束后按约定期限删除。

未成年人可以报名吗？

可以，需要由监护人报名并签署录音同意书，进度报告同步发给监护人。
